# PDF.js 5.6.205

Mozilla PDF.js, https://github.com/mozilla/pdf.js
Apache License 2.0; see LICENSE.

Unmodified minified legacy browser builds from pdfjs-dist 5.6.205:
- legacy/build/pdf.min.mjs -> pdf.mjs
- legacy/build/pdf.worker.min.mjs -> pdf.worker.mjs

All CV pages are rendered as a continuous scrollable document with selectable
text and link annotations, avoiding
reliance on a browser's built-in PDF plugin. No external service receives the PDF.
Text-layer styles in editorial-pdf.css are adapted from PDF.js web/pdf_viewer.css.
